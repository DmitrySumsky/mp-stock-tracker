# Changelog

## [3.1.0] - 2026-08-01

### Fixed
- **Остатки WB собираются заново.** WB отключил `statistics-api…/v1/supplier/stocks`
  20.07.2026 (заглушка `PLUG-404-20260720`, release-notes id=494) — сбор переведён на
  асинхронный отчёт «Остатки на складах» `seller-analytics-api…/v1/warehouse_remains`
  (заказ → статус → скачивание, боевой замер ~8 с на кабинет).
- `fetchWithRetry` больше не ретраит 4xx (кроме 429) и **кладёт в ошибку тело ответа**.
  Раньше в Telegram уходило «HTTP 404 (после 3 попыток)», хотя WB прямо в теле писал
  причину и ссылку на релиз-ноты; заодно 8 мёртвых кабинетов переставали жечь ~50 с
  из шестиминутного лимита GAS.
- 429 пережидается по заголовку `X-Ratelimit-Retry`, а не вслепую.
- `healthCheck()` проверял тот же отключённый URL и врал по всем WB-кабинетам —
  переведён на новую ручку; в текст отказа добавлено тело ответа.
- OZON: ответ с 0 строк больше не выглядит успехом. `writeOzonSheet_` на нуле строк
  выходил до `clearContents()`, лист оставался со вчерашними данными, а в отчёт шло
  «✅ +0» — теперь это явная ошибка кабинета.

### Changed
- Колонки `Цена` и `Скидка` на листах WB остаются пустыми: новый отчёт их не отдаёт.
  Раскладка листов не меняется, история не ломается.
- Псевдосклады отчёта: `В пути до получателей` и `В пути возвраты на склад WB`
  пишутся строками (как это делал старый API), `Всего находится на складах`
  пропускается — это сумма, она удвоила бы любой SUM по листу.

### Требуется от владельца кабинетов
- Новый отчёт живёт в разделе прав **«Аналитика»**. Токены, выпущенные только со
  «Статистикой», получают 401 `token scope not allowed` и требуют перевыпуска в ЛК:
  `seller.wildberries.ru/supplier-settings/access-to-api`.

## [3.0.0] - 2026-03-30

### Added
- Интеграция МойСклад: выгрузка остатков с себестоимостью в лист «Остатки МС»
- Поле API-токена МойСклад в Панели управления (B5)
- Модуль «Кредиты»: синхронизация остатков по кредитам в Управленческий баланс
- Мульти-чат Telegram (несколько chat_id через `;`)
- Дашборд с автообновлением и экспортом в CSV
- Разбивка монолита на модули (`src/00_constants.gs` … `src/99_menu.gs`)

### Changed
- Меню переименовано: «📦 Остатки МП и другие скрипты» → «Автоматизация»
- Подменю разделены на три независимых модуля: Остатки маркеты / Остатки МС / Кредиты
- `TABLE_START_ROW` сдвинут с 7 на 9 (добавлен блок МойСклад в строках 4-5)

### Security
- Удалены захардкоженные Telegram-токен и chat ID из функции миграции

## [2.x] — Предыдущие версии

Монолитный скрипт с поддержкой OZON и WB, без МойСклад и модуля кредитов.
